Виджет для iPhone

Показывает день курса, вечерний уход и Базирон на сегодня, в среднем размере ещё и завтрашний день. Нажатие на виджет открывает график.

  1. Установите из App Store бесплатное приложение Scriptable.
  2. Нажмите жёлтую кнопку ниже — код скопируется.
  3. Откройте Scriptable, нажмите «+» в правом верхнем углу, вставьте код. Нажмите на заголовок «Untitled Script» и назовите «Ретинол». Нажмите «Done».
  4. Долго жмите на пустое место экрана «Домой», затем «+» или «Изменить» → «Добавить виджет», найдите Scriptable, выберите малый или средний размер.
  5. Нажмите на появившийся виджет (в режиме редактирования) и в поле Script выберите «Ретинол».
  6. Для экрана блокировки: долго жмите на экран блокировки → «Настроить» → поле под часами → Scriptable, затем так же выберите скрипт «Ретинол».
Отметки с сайта виджет не видит, он показывает только план. iOS обновляет виджет сама, обычно раз в 15–60 минут, поэтому новый день может появиться не сразу после полуночи.
